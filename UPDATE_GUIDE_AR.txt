تحديث مشروع تبارك إلى v1.2 — طلبات المشرف

1. احتفظي بالنسخة الحالية قبل التحديث.
2. فكّي ضغط ملف v1.2. افتحي مستودع تبارك الموجود على GitHub (لا تنشئي مستودعاً جديداً).
3. Add file → Upload files. ارفعي محتويات مجلد الكود (app.py وanalysis.py وai_model.py وevaluation.py وadvanced_evaluation.py وrequirements.txt وبقية المجلدات والملفات). لا ترفعي ملف ZIP نفسه. تأكدي أن app.py في جذر المستودع.
4. Commit changes على الفرع الحالي main (أو الفرع الذي يستخدمه التطبيق).
5. افتحي رابط Streamlit الحالي لتبارك، وتأكدي من ظهور v1.2 أعلى التطبيق.
6. افتحي Evaluation وانزلي إلى D. AI algorithm comparison — v1.2.
7. اضغطي Run AI algorithm comparison، واحفظي جدول المقارنة وصورة الرسم وملفات النتائج.
8. انزلي إلى E. Scalability — 100 to 5,000 rules واضغطي Run scalability benchmark (100–5000). احفظي جدول القياسات والمنحنى وملف الأزمنة الخام.
9. ملفات results/v1.2_local تحتوي على نتائج فعلية من بيئة التطوير المحلية، وليست قياسات السيرفر السحابي. أعيدي القياس داخل التطبيق لتوثيق أزمنة السحابة. لا تستخدمي أرقاماً محلية على أنها سحابية.
10. لا حاجة لإعادة التجارب القديمة؛ تبقى موجودة في Evaluation. لا تحذفي النسخة القديمة قبل التأكد من عمل الجديدة.

ملاحظة: المقارنة الجديدة تستعمل بيانات اصطناعية ذات حالات غير اعتيادية معروفة عند التوليد. لا تعني اكتشاف هجمات حقيقية. برنامجنا يبقى نموذجاً سحابياً لتحليل قواعد Firewall وليس جدار حماية حقيقياً. تم فحص 17 اختباراً للكود وقياس جميع الأحجام المطلوبة محلياً، لكن لم تتوفر مكتبة Streamlit في بيئة الاختبار المحلية، لذلك لم يتم تشغيل الواجهة الجديدة هنا ويجب التحقق منها بعد الرفع.
